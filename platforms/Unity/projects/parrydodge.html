ParryDodge

Solo project  ·  Unity  ·  Active prototyping

Overview

A stylized combat systems sandbox currently in active prototyping. The core loop revolves around tight timing windows for parries and dodges — rewarding precise reads over button mashing.

Features

🛡️ Frame-precise parry system with visual and haptic feedback
💨 Directional dodge with recovery windows and risk/reward
🎨 Stylized visual direction — bold outlines, minimal palette
🔬 Sandbox design — rapidly iterable combat feel prototyping
