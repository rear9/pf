BeatPunkMania

Little Isopod  ·  Published by Dlala Studios  ·  2024

Overview

A rhythm-action game built in Unity over three months with a 7-person team, published by Dlala Studios. I handled systems programming and build engineering — keeping the project shippable while building the mechanical backbone the rest of the team worked on top of.

My Contributions

🎮 Game flow — scene transitions, state machines, win/lose conditions
🖥️ UI/UX — menus, HUD, settings, in-game feedback
⚙️ Core systems — input handling, score tracking, rhythm sync
🔧 Build maintenance — Perforce pipeline, branch management, release builds
